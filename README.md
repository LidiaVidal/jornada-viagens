# ✈️ Jornada Viagens

> "Somos uma agência apaixonada por criar viagens inesquecíveis. Do destino à seleção das atividades, cuidamos de todos os detalhes para que você aproveite ao máximo cada momento da sua jornada!"

## 💻 Sobre o projeto

O **Jornada Viagens** é um site institucional fictício para uma agência de turismo, construído com foco em boas práticas de estruturação web e design responsivo. O projeto simula a interface de uma plataforma de viagens, contendo uma página inicial de conversão (com ofertas, categorias e destinos populares) e uma página dedicada a pacotes específicos de viagem.

Este projeto foi desenvolvido com base nos ensinamentos e desafios propostos nos cursos da **Alura**, visando consolidar conhecimentos em Front-End.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído puramente com tecnologias web fundamentais, sem a utilização de frameworks, para aprofundar o domínio estrutural:

* **HTML5:** Estruturação semântica do conteúdo, garantindo acessibilidade e boa organização das seções (Home e Pacotes).
* **CSS3:** * **Arquitetura Modular:** Separação inteligente de responsabilidades. O CSS foi dividido em arquivos menores e específicos para cada componente (como `header.css`, `footer.css`, `hero.css`, `destinations.css`), centralizados através do `style.css`.
    * **Design Responsivo (Mobile First):** Utilização de *Media Queries* para adaptar perfeitamente o layout e as imagens (Hero, Galerias) para resoluções de Mobile, Tablet e Desktop.
    * **Variáveis CSS:** Uso de variáveis globais (`:root`) no `global.css` para paleta de cores (primária, secundária, background) e pesos tipográficos, facilitando a manutenção do tema.
* **Tipografia:** Integração de fontes customizadas (`Montserrat`).

## ⚙️ Funcionalidades

- Interface totalmente responsiva.
- Navegação entre múltiplas páginas (`index.html` e `pacotes.html`).
- Menu *hamburger* funcional para dispositivos móveis feito apenas com CSS (`input type="checkbox"`).
- Seções de vitrine de ofertas, destinos populares e prova social (depoimentos).

## 🚀 Como executar o projeto

Como o projeto é feito apenas com HTML e CSS estáticos, não é necessário nenhum ambiente de execução complexo.

1. Clone este repositório:
   ```bash
   git clone [https://github.com/LidiaVidal/jornada-viagens.git](https://github.com/LidiaVidal/jornada-viagens.git)
  1. Abra a pasta do projeto no seu editor de código (como o VS Code).
  2. Abra o ficheiro `index.html` no seu navegador de preferência ou utilize a extensão *Live Server* para visualização com recarregamento automático.
